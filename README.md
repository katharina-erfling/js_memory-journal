# js_memory-journal
**Memory Journal** ist eine lokale Desktop-Anwendung für persönliche Erinnerungen, Fotos und kreative Journals. Die Anwendung verbindet digitales **Fotoalbum, Scrapbook, Tagebuch und Bullet Journal** in einer gemeinsamen Umgebung. Im Mittelpunkt steht ein persönliches Bücherregal
